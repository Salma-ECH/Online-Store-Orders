## Online Store Workflow

**Edited by:** ECHCHERAOUI Salma  
**Last edited:** 08/09/2026

This workflow receives orders via a webhook, validates the required fields, checks for duplicates, saves them in a database, processes new orders through an external API, updates the order status, notifies the team, and catches any potential errors.
